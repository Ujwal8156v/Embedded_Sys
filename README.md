## 📌 Overview

This repository houses the core web application for the **Embedded Systems Domain Hub**. It combines a modern developer portfolio showcasing hardware/software projects with live simulated dashboards for IoT, telemetry monitoring, sensor data readouts, and microcontroller device control.

### 🌟 Key Highlights

- 🎛️ **Live MCU Telemetry Hub (`Embedded.html`)**: Real-time interface simulating GPIO control, pin states, sensor logs, and system status for microcontrollers like ESP32 & Arduino.
- 🌤️ **Weather Monitoring Station (`embd.html`)**: Compact live dashboard displaying temperature, humidity, and atmospheric metrics (simulating DHT11 + ESP8266 hardware data).
- 💼 **Interactive Engineering Portfolio (`index.html`)**: Displays technical skills across C/C++, Embedded C, Python, RTOS, ARM, PCB design, VLSI, along with direct GitHub repository integration.
- 🔐 **Authentication Gateway (`Login.html`)**: Styled login interface for portal access.
- 📄 **Curriculum Vitae Download (`My_CV.pdf`)**: Integrated access to full engineering credentials and résumé.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Ujwal8156v/Embedded_Sys.git
cd Embedded_Sys
```

### 2. Run Locally

No build tools or heavy node servers required! You can launch the project directly in your browser:

- **Option A (Direct File)**: Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
- **Option B (VS Code Live Server)**:
  1. Open the repository folder in Visual Studio Code.
  2. Right-click `index.html` and select **Open with Live Server**.
